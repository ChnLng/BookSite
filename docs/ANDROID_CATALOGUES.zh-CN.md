# Android 翻页目录

更新：2026-08-30。

- 个人版：`/collections/android`，最后一页为免费测试申请和通用安装指南。
- 机构版：`/collections/android-professionnels`，最后为批量授权、开发报价、交付方式及责任条款，不展示免费测试营销页。
- 两版共用玻璃书册界面，按键翻页、键盘左右键、手机横向手势和可点击目录。关闭 JavaScript 时显示所有页及锚点链接；打印时逐页输出。
- 页面不进入首页、导航和 sitemap。HTML robots 与 HTTP X-Robots-Tag 设置 noindex/nofollow；不通过 robots.txt 阻止抓取，避免爬虫无法读取 noindex。
- **仅不公开入口，不是密码保护。** 链接可以被转发，不在页面中放合同机密或用户信息。

## 管理员配置

在 Supabase SQL Editor 执行 `supabase/migrations/20260830_android_catalogues.sql`。脚本可重复运行且不会覆盖已保存版本。当前用户 `profiles.role` 必须为 `admin`；不需要新增 service role 环境变量。

后台 → 商品与内容 → Android 翻页目录：分别编辑两版封面、应用文字、显示与排序。个人版可关闭测试页；B2B 可修改授权阶梯、开发套餐、交付与退款条款。关闭目录将让该地址返回 404。保存采用版本号，拒绝覆盖他人刚保存的版本。应用链接固定绑定五个已知包名。

尚未安装迁移时使用代码中内置的初始版本，后台明确不能保存。迁移存在后，数据库故障不回退到内置版，以免把管理员已停用的目录重新显示出来。数据库原始配置表不可匿名直接读取；只读函数仅返回启用的目录，管理函数另行校验 admin。

## B2B 报价草案（非自动收费）

当前初始建议为：1–11 份按原价 100%，12–29 份 80%，30–59 份 70%，60–119 份 60%，120 份起 50%。同一机构、同一应用、同一订单计量，按报价中的不含税参考单价计算。

- 已有应用教学适配：1,800 € HT。
- 全新单模块应用：3,900 € HT。
- 全新最多三个模块应用：5,900 € HT。

范围严格限定到页面列明的屏幕、模块、语言、反馈轮次；素材由客户提供。默认不含服务器、API、AI、学生账户、支付或 iOS。应用商店原价不完整时不得猜测；最终基价、VAT、授权身份、安装交付方式需在 devis 中确认。**不出售或承诺无限供应免费 Google Play 促销码。** 没有实现 B2B 下单收费或实际授权发放。

目录显式标“报价草案”。管理员确认具体商业条件后，可取消提示；即使取消，最终交易仍需独立 devis 和合同，目录不自动构成已签协议。

## 两个月交付与责任草案

- 从签约、首款、材料与必要权限齐备起，以两个月完成开发、校内使用、验收及提交上架为目标。Google 的审核、生产权限批准不能承诺两个月内完成。
- 学校至少 12 名成员连续加入 14 天且实际使用，汇总反馈。Google 此项最低人数规定针对其文档列明的新个人开发者账户，不能泛称适用于所有账户；校内协作要求另在合同规定。
- 30% 启动、40% 中间版本、30% 最终验收；不是默示验收。
- 自身原因延期，书面通知后给 15 天补救期；仍未完成则终止未履行部分，14 天内退还未交付或无法使用部分。独立可用且已验收的部分保留价款；若无可用交付则退该项目已收款。
- 不承诺额外定额补偿，并拟限制间接损失和直接损失责任上限，但不排除法律强制责任、故意、重大过失、人身损害等。不能以“只退款、任何情况下不赔偿”免除核心义务。
- 这是合同起草建议，不是专业法律意见。签约前应由法国法律专业人士结合经营主体、客户类型、税务和知识产权审查。
